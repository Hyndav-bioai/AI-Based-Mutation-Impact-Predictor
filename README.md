# AI-Based Mutation Impact Predictor

## Project Overview
This project explores how changes in DNA sequences can affect codons and protein sequences.

## Objectives
- Compare reference and mutated DNA sequences.
- Identify individual sequence variations.
- Classify coding consequences such as synonymous, missense, and nonsense when the required coding context is available.
- Present results in an interactive dashboard.

## Technologies
HTML, CSS, JavaScript, and any additional tools actually used in the project.

## Disclaimer
This is an educational prototype, not a clinically validated diagnostic tool.
